Interpretation

What XGBoost has learned to look for

    Each point is one test customer. Red is a high feature value, blue a low one. Points right of zero push the model towards “subscribes”.

    01Previous campaign succeededThe strongest push towards “yes”.
    02Contact method unknownPushes the prediction towards “no”.
    03Called many times this campaignMore calls so far, lower predicted chance.

    These are associations, not causes. Less interested customers may simply receive more calls.

    Call down a ranked list instead of using one probability cut-off.

    Profit

    Build the rule from call cost and deposit value. F1 ignores both.

    Limitations

    What this evaluation can't tell us yet

    One dataset, one split

    Earlier project versions had already looked at the test set.

    Uneven tuning

    18 forest settings, 4 per neural model, 10 per boosting model. One seed.

    A close call at the top

    The XGBoost vs CatBoost bootstrap interval reaches zero, so the gap is not decisive.

    Prediction is not cause

    Capture counts subscribers on a list, not subscriptions that a call creates.

    Next step

    Test the shortlist on a fresh, later campaign

    • Equalise tuning budgets and repeat across seeds
    • Check probability calibration
    • Set the contact rule from the bank's capacity and costs

    Thank you
